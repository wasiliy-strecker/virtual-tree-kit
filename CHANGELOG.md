# Changelog

All notable changes to Virtual Tree Kit are documented in this file.

## [0.1.0] - 2026-07-24

### Added

- immutable, iterative tree indexing with stable validation errors
- framework-independent visible projection and ARIA hierarchy metadata
- pure keyboard navigation and accent-insensitive wrapping typeahead
- fixed-row range calculation and four scroll alignment strategies
- typed headless `useVirtualTree` hook
- unstyled `VirtualTree` reference component
- controlled and uncontrolled expansion and single selection
- stable container focus with mounted `aria-activedescendant` guarantees
- 50,000-node interactive showcase deployed through GitHub Pages
- unit, property, public API type, packaging, Chromium, and Axe evidence
- ESM and CommonJS package outputs with declaration files and source maps

### Deliberate limits

- fixed-height rows only
- synchronous child arrays only
- single selection only
- no drag-and-drop or focusable row controls
